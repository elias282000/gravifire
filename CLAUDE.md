# GRAVIFIRE integration notes

The current Next.js application is the primary runtime. Preserve its
Mission Control game, scientific routes, evidence contracts, and tests when
adding research artifacts.

The `Gravifier_research/` and `psidata/` trees are provenance-bearing source
material from the integrated data repository. Do not rewrite raw NASA data or
silently normalize conflicting source files. Every displayed scientific value
must remain traceable to its source record and field.

The application must not overclaim. Use source-scoped language such as
"records", "under these tested conditions", and "current archive". Keep
fictional Mission Control story context separate from NASA evidence.

Never commit secrets, local environment files, dependency directories, build
outputs, or downloaded raw-data caches. Keep both application and research
histories intact when resolving merges.
