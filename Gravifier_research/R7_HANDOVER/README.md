## The one rule that cannot bend

**No client-side numbers.** Any numeric literal the app renders must carry a
key in `numbers_whitelist.json` and match its `render_as`. No computation,
conversion, averaging, or rounding beyond display. Ever. (Dev doc §8 rule 1
+ rule 15.)

## Verify (run this first)

```bash
python3 verify_bundle.py        # expect: all PASS, exit 0
```

## Regeneration (research side; app never needs these at runtime)

```bash
# verdict outputs (deterministic over frozen inputs)
cd engine && python3 run_r3.py            # 18/18 literature concordance
python3 scripts/r5_build_digest.py        # rebuilds R5_DIGEST_DATA.json (run from verdict_engine/ in repo)
```

The app ships static JSON generated by these scripts — no backend, no API.
EMBER's LLM (if used) is called via serverless wrapper or pre-cached lines,
never from the browser with a public key.
