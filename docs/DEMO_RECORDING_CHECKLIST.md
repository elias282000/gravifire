# GRAVIFIRE Demo Recording Checklist

## Before recording

- Production build succeeds.
- Use a clean browser profile.
- Prefer 1920×1080.
- Browser zoom is 100%.
- Notifications are disabled.
- DevTools are closed.
- No console is visible.
- Open `/mission-control?demo=1`.
- Verify the M1 route/state is reachable.
- Verify the M4 route/state is reachable.
- Verify the M6 route/state is reachable.
- Verify `/mission-control/dossier`.
- Close unrelated tabs.
- Test pointer lock before recording.
- Check microphone if recording narration.
- Keep the cursor visible only when it helps the interaction.

## Record clips

1. Queue intro.
2. M1 comparison.
3. M4 hero contrast.
4. Four-sample matrix.
5. M6 door approach.
6. M6 refusal.
7. Campaign experiment memo.
8. Dossier.
9. One source evidence drawer.
10. Optional Experiment Explorer overview.

Record both clean individual clips and one uninterrupted demo where possible.

## Editing principles

- Do not speed up or alter scientific numerical displays misleadingly.
- Cuts are allowed, but do not imply that navigation was scientific observation.
- Use simple captions.
- Avoid excessive cinematic effects.
- Preserve source IDs and limitations on screen.

## Suggested captions

- REAL NASA DATA
- SAFFIRE-I / PSI-98
- RECORDED BURN TIME
- SAFFIRE-II / PSI-99
- SCHEMATIC EVIDENCE REPLAY
- CURRENT ARCHIVE LIMITATION
- REFUSAL
- NEXT EXPERIMENT

Never caption a result as NASA-approved, AI-predicted Mars fire, or a safety classification.

## End-of-session recovery

- Return to `/mission-control`.
- Confirm the Dossier still opens.
- Confirm the demo route did not alter the normal campaign state.
